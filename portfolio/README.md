# Om Tiwari — Minimal Portfolio

Responsive one-page portfolio built with plain HTML, CSS, and JavaScript.

## Run it
Open `index.html` in a browser or use VS Code Live Server.

## Personalize before publishing
1. Open `script.js`.
2. Replace `YOUR_EMAIL@example.com` with the email address where you want to receive messages.
3. Replace the empty `LINKEDIN_URL` with your LinkedIn profile URL.

## Contact form
The front-end-only contact form opens the visitor's default email app with the fields filled in. The visitor must press Send. Sending directly from the website without opening an email app requires a backend or email form service.
